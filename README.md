# MAKARIA

Aplicativo financeiro pessoal com Supabase, lançamentos por categoria/ícone, metas, salário configurável, gráfico de pizza e gráfico de despesas.

## 1. Supabase
No SQL Editor do seu projeto, cole o conteúdo de `supabase.sql` e execute.

## 2. GitHub Pages
Envie todos os arquivos para o repositório `MAKARIA-FINAN-AS`. O `index.html` é a página inicial.

## 3. Login
O cadastro começa com valores financeiros zerados. Cada usuário possui seus próprios dados por meio das políticas RLS do Supabase.

## 4. Ajustes
Alterações de salário e percentuais ficam salvas na tabela `settings` e reaparecem no próximo acesso.
